# PROJECT HEALTH DASHBOARD | POWER BI 

## Project Overview
This is one of my first Power BI dashboard that I would like to share publicly. Developed to track project progress, status, the company's budgets and expenses across projects managed by different managers. 

This dashboard is created to help managers and project teams review the rate of project progress, locations, priorities or even the completion percentages. It mainly focuses on PROJECT LOCATIONS, PROJECT #ID, TOTAL EXPENSE, PRIORITY, PROJECT ID STATUS that helpful to identifying whether the projects needs more attention

## Tools & Skills I Used:
- Power BI desktop: Built an attractive and interesting dashboard, applied core charts, converted data
- Power Queries: Transformed data from raw file to categorize which columns are essential to use in PowerBI, corrected column data types
- Data visualization: Used 4 KPIs cads to display key metrics, utilized a map, a donut chart and bar charts to compare the difference of progress from each project managers.
- Dashboard Design: Visualized layouts, labels, colors and filter cards to make a dashboard look easy and clean to read.
